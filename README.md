# houKache
Houdini caching tool for FX projects, part of KA Tools.

This tool is effectively a wrapper for useful caching functions within Houdini, to be used in place of the filecache node and includes:
- Single and multi-frame caches (in progress)
- .vdb and .bgeo support (in progress)
- Version control (in progress)
- Houdini native file management (in progress)
- Exposed wedging parameters (in progress)
